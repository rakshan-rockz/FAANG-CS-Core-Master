# Hint: $ARGUMENTS

1. Identify what the learner is working on (the current Hook/probe/lab, or the argument). If it's outside a
   session, ask what they've tried and what their current model is.
2. Find the current rung: the highest already given for this item in this conversation. If none, first ask
   "What's your current model / prediction, and where exactly does it break down?" — answering that is H0.
3. Give **exactly the next rung** (roadmap README §6):
   - **H0**: a question about the process ("How many processes exist after the call? Which one returns?").
   - **H1**: which layer or resource to think about ("Think about what the kernel copies for the child.").
   - **H2**: one specific fact about this mechanism, still not the whole thing.
   - **H3**: the mechanism's skeleton (the state/invariant/structure), for the learner to assemble.
   - **H4**: the full explanation (the learner still explains it back in their own words).
4. ≤ 5 lines. End by handing it back: "Try that. Want to keep going?"
5. "Just tell me" → one rung up; the full answer only if asked again.
6. Record the rung for wrap-up: it affects the mastery status and moves the concept's first spaced review to +1
   if H2–H3 was needed (H4 → schedule a repeat derive-back next session).

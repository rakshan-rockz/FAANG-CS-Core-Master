# Phase 5 — OS: Memory Virtualisation

OSTEP chapters 13–23 and CS:APP 9. How every process gets a private, huge, contiguous-looking address space
on top of shared, fragmented physical RAM: translation, paging, TLBs, multi-level page tables, swapping and
replacement, allocators, `mmap` and copy-on-write. Virtual memory questions (paging, TLB, page faults,
thrashing, LRU) are core-subjects staples, and the numericals (page-table size, EAT, fault counts) are asked
on paper.
**Xref:** Phase 2 caches (TLB is a cache; VIPT L1 needs the page offset); Phase 3.2.3 fork → COW finished
here; SD 0.3.2 page cache at design level; DSA implements LRU as a data structure, here LRU is a policy and
its approximations. Phase 11.1.3 buffer pools spiral back to replacement policies.
**Reading:** OSTEP 13–23; CS:APP 9.

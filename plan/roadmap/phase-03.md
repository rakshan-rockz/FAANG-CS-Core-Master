# Phase 3 — Linking, Loading & Exceptional Control Flow

CS:APP chapters 7, 8 and 10. How source becomes an executable, how an executable becomes a process, and how
control leaves the normal instruction stream (interrupts, traps, faults, signals). `fork`, `exec`, `wait`,
signals, system calls and file descriptors are learned here from the program's side; Phase 4 revisits the
same machinery from the kernel's side.
**Xref:** SD 0.3.1 names user/kernel space and system calls at design level; this phase shows the actual
trap, the ABI and the cost. Phase 5.3.4 completes copy-on-write `fork`; Phase 7.3 completes the kernel I/O
path; Phase 8.2 builds network servers on top of the file-descriptor model.
**Reading:** CS:APP 7, 8, 10; Levine *Linkers and Loaders*; Drepper *How To Write Shared Libraries*;
Kerrisk *The Linux Programming Interface* (TLPI) ch 3, 20–22.

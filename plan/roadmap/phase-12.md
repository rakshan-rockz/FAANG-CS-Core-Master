# Phase 12 — Programming Languages & Compilers

OOP fundamentals as interview theory and as machine reality (the C++ object model: layout, vtables, RTTI,
multiple inheritance), memory management from RAII to reference counting to tracing and generational GC, type
systems and binding, then the full compiler pipeline — lexing, parsing, semantic analysis, IR and SSA,
optimisation, register allocation, code generation — and interpreters, bytecode VMs and JITs. Three lab
sessions build a Lox-subset interpreter in C++ (tree-walker, then bytecode).
**Xref:** the LLD course (sibling repo, if present) owns OOP *design* (SOLID, design patterns, class design,
UML); this phase owns the OOP interview theory and the mechanism underneath. DSA Stage 0 X2 owns C++
interview-coding pitfalls. Earlier phases: 1.3 (stack, ABI, struct layout), 2.1.3 (branch prediction ↔ virtual
calls), 3.1 (linking, vtables in ELF), 5.3 (allocators ↔ GC), 14.1–14.2 (regular and context-free languages ↔
lexing and parsing).
**Reading:** Lippman *Inside the C++ Object Model*; Itanium C++ ABI; Jones, Hosking & Moss *The Garbage
Collection Handbook* 2e; Nystrom *Crafting Interpreters* (CI); Cooper & Torczon *Engineering a Compiler* 3e;
Aho et al. *Compilers* (Dragon) 2e ch 4.

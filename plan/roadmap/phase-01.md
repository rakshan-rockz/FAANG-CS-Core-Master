# Phase 1 — Data Representation & Machine-Level Programming

CS:APP chapters 2–3. Every value above this layer is a bit pattern plus an interpretation. Integer
overflow, signed/unsigned bugs, floating-point surprises, and the stack-smashing attacks of Phase 13 all
live here. By the end the learner reads x86-64 the compiler produced and explains a stack frame byte by
byte.
**Xref:** DSA Stage 0 X2 covers C++ overflow/`size_t` pitfalls at *interview-coding* level (how to avoid
them); this phase explains *why* they happen in the hardware and the language standard. Phase 13.5.1
spirals back to memory-safety exploits.
**Reading:** CS:APP 2.1–2.4, 3.1–3.10; Goldberg 1991; Aleph One 1996.

# Phase 2 — Processor & Memory Hierarchy

CS:APP chapters 4–6 (and 5 for optimisation). Why the same Big-O can differ 10× in wall time: pipelines,
branch prediction, out-of-order execution, caches, coherence. This is the performance intuition every later
phase leans on: TLBs (5.1), false sharing and memory models (6.4), buffer pools (11.1), side channels (13.5).
**Xref:** SD 0.3.2 and 0.3.4 state the hierarchy and its numbers for design estimation; this phase
explains the mechanisms and measures them on this machine. DSA's complexity analysis ignores constants;
here the constants are the subject.
**Reading:** CS:APP 4.1–4.5, 5, 6; Drepper 2007; Sorin/Hill/Wood *A Primer on Memory Consistency and Cache
Coherence* 2e.
**This machine:** i7-13620H (6 P-cores with HT + 4 E-cores). Always pin benchmarks (`taskset -c`) and
report which core type.
